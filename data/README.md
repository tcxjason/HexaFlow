## 二、来源与再加工

- **来源**：ima 个人知识库「资料 / 易经 / 知识库」
- **再加工**：**仅提取经文原文**，已剥离上游随附的现代译文、白话翻译与注解（那部分属现代作者作品，不随本仓库分发）；`08-杂卦传.md` 另去除知识库原文中的夹注，保留卦名标记《》
- **版权**：经文本身为先秦典籍，属**公有领域**
