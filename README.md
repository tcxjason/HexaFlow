# 易经占卦解卦 Skill · yijing-divination

> 一个可直接装进 AI Agent 的**易经占卦解卦技能**：你只需报出「本卦 + 变爻」，它自动推出之卦、按朱熹《周易本义》确定该引哪些经文，并从知识库取原文，输出结构化的解卦报告。

---

## 这是什么

`yijing-divination` 是一份遵循 Agent Skill 规范的技能包（SKILL.md + references + scripts）。它的判定链路是：

**识别意图 → 规范化输入 → 确定引用范围 → 检索原文 → 结构化输出**

核心原则：**所有经文引用都必须来自知识库检索结果并标注出处，不凭记忆输出，不杜撰。**

## 特性

- **输入极简**：只需本卦卦名 + 变爻位置；之卦与爻题由技能自动推导，无需你提供。
- **依据经典**：解卦引用范围严格遵照朱熹《周易本义》七原则（见下）。
- **原文可溯**：每条【原文】都括注出处文件（如「（《彖传上下》）」）。
- **四段式输出**：占卦结果确认 → 卦象含义 → 爻辞解读 → 综合判断。
- **硬边界**：不作数值化预测（不写金额／百分比／收益率）、不作吉凶承诺、不给投资医疗法律等专业决策建议。

## 安装

### 方式一：从 GitHub 克隆（推荐）

装到 **用户级技能目录**（所有项目通用）：

```bash
# macOS / Linux
git clone https://github.com/tcxjason/yijing-divination.git ~/.workbuddy/skills/yijing-divination
```

```powershell
# Windows PowerShell
git clone https://github.com/tcxjason/yijing-divination.git "$env:USERPROFILE\.workbuddy\skills\yijing-divination"
```

> 目录名必须是 `yijing-divination`，与 `SKILL.md` 里的 `name` 保持一致。

### 方式二：从 ima 知识库还原

见 [`docs/ima-restore.md`](docs/ima-restore.md)。

| 依赖 | 说明 |

| ima 连接器 + 同一 ima 账号 | 技能运行时要读取「资料 / 易经 / 知识库」中的典籍原文 |

## 使用方法

### 触发方式

用自然语言说出需求即可，技能由以下触发词唤起：
**解卦、占卦、占卜、起卦、卦名、变爻、爻变、之卦、本卦、解此卦、周易、易经、蓍草、大衍之数、六十四卦。**

### 主场景：解卦

**输入要求**

| 项 | 必填 | 说明 |
| --- | --- | --- |
| 本卦 | ✅ | 卦名（`巽`）／全称（`水天需`）／卦序（`57`）／上下卦组合（`巽上巽下`）任一形式 |
| 变爻位置 | ✅ | `1–6` 数字，或 `初/二/三/四/五/上`，或爻题（`六二`、`上九`）；**多爻变用逗号分隔**。静卦须明确说明「无变爻」 |
| 所问事项 | ⬜ | 用于综合判断的情境（如「近半年财运」）。不提供则只作卦理趋势串讲 |
| 之卦 | ⬜ | 若提供，会与本卦 + 变爻交叉校验；不一致时**以本卦 + 变爻为准** |

**示例**

```
使用技能 yijing-divination，解卦：
咨询「未来一段时间的财运」（约 3 个月~半年），
占得本卦「巽」，初六和上九两爻变。
```

技能会自动推导出之卦为「水天需」，判定依朱熹七原则第 3 条「二爻变以上爻为主」，
再检索《卦辞爻辞》《彖传上下》《象传上下》原文，输出四段报告。

### 其他意图

| 意图 | 示例问法 | 输出 |
| --- | --- | --- |
| 占筮方法咨询 | 「蓍草法怎么用」「大衍之数五十」 | 《系辞传》原文 + 分步白话（只推荐经典筹策法） |
| 单一卦爻查询 | 「乾卦九二什么意思」「解释一下睽卦」 | 卦辞／传注 + 白话，不涉变爻与情境 |
| 易学义理探讨 | 「什么是太极」「当位怎么判断」 | 以《系辞传》《说卦传》等原文为据阐释 |

### 输出结构（解卦）

```
一、占卦结果确认   本卦 / 变爻 / 之卦 + 引用依据
二、卦象含义       本卦（卦辞 · 彖传 · 大象），之卦按需展开
三、爻辞解读       变爻爻辞 + 小象 + 爻位分析（当位／得中／应／乘承）
四、综合判断       结合所问事项串讲义理脉络，给出行动向度与所守之德
```

## 命令行工具（可选）

`scripts/divine_gua.py` 可独立运行，用于确定性推导之卦与引用范围：

```bash
python scripts/divine_gua.py --gua 噬嗑 --changing 六二
python scripts/divine_gua.py --gua 艮   --changing 6
python scripts/divine_gua.py --gua 谦   --changing 2,4
python scripts/divine_gua.py --gua 52                 # 静卦（无变爻）
```

输出示例（噬嗑 · 六二变）：

```
======================================================
本卦：噬嗑（第 21 卦 · 火雷噬嗑，上离下震）
      六爻（自下而上）：100101
变爻：六二（位置 2）
之卦：睽（第 38 卦 · 火泽睽，上离下兑）
      六爻（自下而上）：110101
引用范围：一爻变 → 以本卦变爻爻辞为主，之卦卦辞为辅
======================================================
```

> 该结果与知识库案例《占卦实例：某私人案例》的记载一致，可作自检样本。

## 引用原则：朱熹解卦七原则

| 变爻数 | 引用范围 |
| --- | --- |
| 0（静卦） | 本卦卦辞 |
| 1 | 本卦变爻爻辞（含小象） |
| 2 | 本卦两个变爻爻辞，**以上爻为主** |
| 3 | 本卦与之卦卦辞，**以本卦为主** |
| 4 | 之卦中两个不变爻的爻辞 |
| 5 | 之卦中不变爻的爻辞 |
| 6 | 乾→坤取乾「用九」；坤→乾取坤「用六」；其余取之卦卦辞 |

完整原文与爻位判读规则（当位／得中／应／乘承）见 [`references/jiugua-rules.md`](references/jiugua-rules.md)。

## 边界与免责

1. **不作数值化预测**——不出现收益率、金额、百分比、概率等量化结论，不预测具体日期。
2. **不作吉凶承诺**——吉、凶、悔、吝、厉、无咎等占验之词照引原文并释义，不外推为结果保证。
3. **不杜撰经文与出处**——检索不到即如实说明。
4. **不越界给专业决策**——不作投资、医疗、法律等专业决策的替代性建议。
5. 本项目**仅承认《易经》体系**；占筮方法只推荐《系辞传》所载经典筹策法（蓍草法）。

> 解卦内容为传统文化与哲学视角的阐发，**仅供参考，不构成任何现实决策依据**。
