## 三、之卦推导算法

1. 取本卦六爻串（自下而上，第 1 位为初爻，第 6 位为上爻）。
2. 对每个变爻位置，将该位阴阳翻转（1→0，0→1）。
3. 变形后的六爻串查表即得之卦。
4. 变爻爻题：位置 1 记「初」、位置 6 记「上」、其余记序数；该位为阳记「九」、为阴记「六」。例如第 2 位为阴 → 「六二」；第 6 位为阳 → 「上九」。

**自检样例一**：噬嗑（21，`100101`）六二（第 2 位）变 → `110101` → 第 38 卦睽（火泽睽）。
**自检样例二**：艮（52，`001001`）上九（第 6 位）变 → `001000` → 第 15 卦谦（地山谦）。

命令行调用：

```bash
python scripts/divine_gua.py --gua 噬嗑 --changing 六二
```

## 四、输入规范化

用户可能以下列任一形式给出本卦，须先归一化：

| 用户表述 | 归一化结果 |
| --- | --- |
| 「艮」「艮卦」「艮为山」 | 第 52 卦，上艮下艮 |
| 「地山谦」 | 第 15 卦，上坤下艮 |
| 「52」 | 艮 |
| 「艮上艮下」「上艮下艮」 | 艮 |
| 「山」 | 有歧义（八经卦之一，但可指上卦或下卦位置），须追问 |

变爻位置归一化：`1/2/3/4/5/6` ↔ `初/二/三/四/五/上` ↔ `初九/六二/…/上六`（爻题可反推阴阳，用于校验本卦爻画）。
