## 三、检索策略

### 3.0 首选：技能目录内 `data/`（随仓库分发，无需外部依赖）

| 目标内容 | 文件 | 锚点格式 |
| --- | --- | --- |
| 卦辞、爻辞 | `data/01-卦辞爻辞.md` | `# <序号>、<卦名>` |
| 彖传 | `data/02-彖传上下.md` | `# <两位序号> <卦名>` |
| 大象、小象 | `data/03-象传上下.md` | `# <两位序号>. <卦名>` |
| 系辞传（含占筮章） | `data/04-系辞传.md` | `# 系辞传·上` / `# 系辞传·下` |
| 说卦传（八卦类象） | `data/05-说卦传.md` | `# 第N章` |
| 文言传 | `data/06-文言传.md` | `# 乾文言` / `# 坤文言` |
| 序卦传 | `data/07-序卦传.md` | 全文连续 |
| 杂卦传 | `data/08-杂卦传.md` | 全文连续 |

**已覆盖全部四类意图所需经文。** 仅当 `data/` 缺失或需交叉核对时，才走下方 3.1 / 3.2 的 ima 知识库路径（可补上《易经历史》《易经》《周易》《易传》摘要、鬼神之说、占卦实例等背景材料）。

### 3.1 回退：知识库内语义检索

```
mcp__ima-mcp__search_knowledge(
  knowledge_base_id = "<KB_ID>",
  folder_id = "<FOLDER_ID_JINGWEN>",   # 限定在典籍目录
  query = "<卦名> 卦辞 爻辞 原文 白话"
)
```

该接口返回体可能极大（实测单次可超 100 KB），超出上下文上限时会自动落盘为 `tool-results/*.txt`。**此时不要整篇读入**，用 Read 指定 offset/limit 或 Grep 在落盘文件中定位目标段落。

### 3.2 备选：取指定文件全文

```
mcp__ima-mcp__fetch_media_content(media_id = "<上表 media_id>")
```

实测《卦辞爻辞》（约 104 KB）可整篇返回，直接按 3.4 锚点定位目标卦即可；若返回体超出上限则落盘，此时用 Read 分块或 Grep 定位。**无论走哪条路径，都不要逐字通读全篇**——只取当前卦所需段落。

### 3.3 检索 query 模板

| 目标内容 | query 模板 |
| --- | --- |
| 卦辞、爻辞 | `<卦名> 卦辞 爻辞 原文 白话` |
| 彖传 | `<卦名> 彖传 白话` |
| 大象、小象 | `<卦名> 大象 小象 象传` |
| 序卦义理 | `<卦名> 序卦传` |
| 杂卦对举 | `<卦名> 杂卦传` |
| 系辞引述（仅当变爻爻辞被《系辞传》引用） | `<爻辞首句> 系辞` |
| 占筮方法 | `大衍之数 五十 蓍草 分二 挂一 揲四 归奇` |
| 义理概念 | `<概念> 系辞传` 或 `<概念> 说卦传` |
| 八卦象征 | `<卦象字> 说卦传 象征` |

### 3.4 段落定位锚点（用于落盘文件内的分块读取）

| 文件 | 段落锚点格式 | 示例 |
| --- | --- | --- |
| 《卦辞爻辞》 | `# <序号>、<卦名>（原文）` | `# 21、噬嗑（原文）` |
| 《彖传上下》 | `# <两位序号> <卦名>` | `# 01 乾` |
| 《象传上下》 | `# <两位序号>. <卦名>（原文）` | `# 01. 乾（原文）` |
| 《说卦传》 | `# 第 N 章` | `# 第一章` |
| 《系辞传》《易经历史》《杂卦传》《序卦传》 | 以 `#` 标题分节 | — |
| 案例文件 | 无分节，整体阅读 | — |

已验证：《卦辞爻辞》中 `# 52、艮（原文）` 段含卦辞「艮其背，不获其身，行其庭，不见其人，无咎。」与上九「敦艮，吉。」，格式与上表一致。

## 四、注意事项

- 「概述」目录（爻位·当位·乘承 等概念图解）已于 2026-10-13 删除。爻位分析不再有图解佐证，一律以《象传》小象与 `jiugua-rules.md` 的规则为据。
- 案例文件仅作范式与校验参照，其既有结论**不作为判读依据**，判读一律以经文为准。
